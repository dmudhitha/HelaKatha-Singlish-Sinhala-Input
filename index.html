Core Features

Everything You Need for Professional Sinhala Typing

⌨️

Phonetic Singlish Input

Type naturally in Singlish (e.g., "kohomada", "mage nama") and watch it convert to accurate Sinhala script (කොහොමද, මගේ නාම) in real-time with intelligent syllable matching.

🧠

Smart Auto-Learning Dictionary

Your typing habits are learned automatically. Frequently used words bubble to the top of suggestions. Personal dictionary persists across sessions in user_dict.json.

🔮

Sentence Prediction (N-Gram)

Context-aware next-word suggestions appear before you even type a character. Learns bigrams on-the-fly for intelligent sentence completion.

⚡

Text Macros with Variables

Create custom shortcuts like hk = හෙළකත. Supports dynamic variables: [date], [time], [clip] (clipboard content) for powerful expansions.

🎙️

Bilingual Voice Typing

Speak in Sinhala or English — auto-switches recognition language based on active mode. Offline Vosk support for privacy. Smart punctuation: "කොමාව" → ,, "තිත" → .

😊

Emoji Search & Insert

Type : to browse popular emojis, or search with queries like :smi, :hea, :lk. Insert directly from the candidate box — no mouse needed.

🔧

Spelling Auto-Correction

Intelligently corrects common phonetic typos like dental vs cerebral confusion (e.g., කරුනා → කරුණා). Works seamlessly within the candidate list.

🎨

Beautiful Light/Dark Themes

Instant theme switching with Catppuccin Latte (light) and Mocha (dark). Floating candidate windows feature smooth animations, drop shadows, and cursor tracking.

Quick Start

Up and Running in Three Steps

1

Install

Run ./install.sh on Linux or install.bat on Windows. Sets up dependencies, virtual environment, and system integration automatically.

2

Launch

Start with python3 main.py (Linux) or double-click run.bat (Windows). The floating language bar appears — click සි/EN to toggle.

3

Type

Press Ctrl+Space to enable Singlish mode. Type phonetically: kohomada → කොහොමද. Press Space or 1-5 to select candidates.
